# Гранула Sentinel-2 по сети: TCI 10 м открывается в канве из хранилища, не
# будучи скачанным, и приезжает выдержками тайлов, а не файлом.
#
# Второй сценарий на удалённое чтение (первый — remote.txt, там NetCDF на
# шаре) и единственный на главный формат каталога по проводу. Ищется сосед
# гранулы из fixtures/s2-tci.txt — та же съёмка, соседняя плитка T31TGK, — и
# сосед нарочно: скачанный снимок приложение открывает с диска, чем бы его ни
# позвали, и провод в таком прогоне не участвовал бы вовсе. Продукт назван
# целиком, его строка адресуется ключом хранилища, как в той фикстуре;
# «Смотреть снимок» в её меню открывает TCI через провайдера.
#
# Ждём то же, что jp2canvas.txt: строку размера, отсутствие подписи предела
# детали, пропажу хода «тайлы N/M» на подгонке и после приближения. По сети
# это полминуты: самый грубый уровень — по пробе с каждого из 121 тайл-парта,
# заказанных сети наперёд (docs/decisions/0005-network-reading.md), по два
# блока в 64 КиБ на пробу, затем куски выдержек всех тайлов вторым заказом.
#
# Шаг `delivered` — ручательство за провод: ни один ресурс не привёз больше
# названной доли своей длины. Сверяет его прогон по строкам `network::perf` в
# trace.log (docs/operations/ui-tests.md). Доля названа по замеру 5 сентября
# 2026 на холодном кэше тайлов (два прогона, байты сошлись до единицы): самый
# грубый уровень просит 7,6 МиБ проб и получает 11 % — по два блока на пробу;
# его куски и подробные уровни приближения докладывают по своим блокам, и к
# закрытию доставлено 24 %. Запас до 35 — на другой набор тайлов при ином
# размере окна или точке приближения.
# Ручательство держит именно это: файл не привозится дважды, а ужесточить
# долю — дело сети (roadmap, шаг 12).
#
