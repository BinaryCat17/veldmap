# Просмотр: открыть скачанный растр и дождаться, пока он покажется.
#
# Единственный сценарий, которому нужны данные: хотя бы один скачанный .tif в
# runtime/data. Строку он не называет по имени — отбирает по расширению и
# берёт первый значок «Открыть», поэтому от того, что именно скачано, не
# зависит.
#
# Проверка кончается отрицанием: «не изображение» — это тот ответ, который
# приложение даёт, не читая ни пикселя, и без этой строки сценарий сошёлся бы
# на отказе так же, как на показе.
100 timeout 40000

1100 tap new_tab:downloaded
1900 wait query
2100 tap query
2400 type .tif
3400 wait preview#1
3600 tap preview#1

4800 absent text:не изображение
