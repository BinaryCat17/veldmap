# Список сужается фильтром, и это не украшение: коробочка стои́т у всякой
# строки, включая файлы сами по себе, а очерчивается только снимок — без
# сужения первая коробочка списка попала бы в файл, и очерчивать было бы

# в списке одни снимки; имя снимка сюда не вписано нарочно — оно у каждого
# своё.

# геометрию контура знает каталог, и другого места взять её нет.
