# Specification: Базовый рендеринг рельефа из DEM

## Обзор
Этот трек направлен на создание фундаментального механизма отображения 3D-рельефа Земли. Мы будем использовать статические файлы цифровых моделей высот (DEM) для генерации полигональных сеток (мешей) и их последующего рендеринга.

## Цели
- Реализовать парсинг данных DEM из существующих форматов (например, GeoTIFF или сырые данные в `data/geoids`).
- Создать алгоритм генерации вершинных и индексных буферов для GPU на основе карты высот.
- Обеспечить интеграцию с текущим движком `wgpu` для отображения рельефа.

## Технические детали
- **Входные данные:** Файлы в директории `data/geoids/`.
- **Генерация меша:** Равномерная сетка, где координата Z определяется значением высоты из DEM.
- **Шейдеры:** Обновление `shader.wgsl` для поддержки освещения и базовой раскраски рельефа по высоте.

## Критерии приемки
- Приложение загружает статический файл DEM при старте.
- На экране отображается 3D-рельеф, соответствующий данным из файла.
- Камера позволяет осматривать рельеф со всех сторон.
- Тесты подтверждают корректность парсинга данных и генерации геометрии.
