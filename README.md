# VeldMap: Архитектура и API

Современная децентрализованная P2P платформа для визуализации ландшафта. Вся логика и интерфейсы вынесены в изолированные WASM-плагины.

## Типы Хостов

- **`veldmap-host-gui`**: Графический клиент (WGPU). Полноценная среда для запуска интерактивных приложений.
- **`veldmap-host-cli`**: Консольный клиент. Используется дляheadless-узлов, не поддерживает графический вывод и сервис `app`.

---

## 1. Системный сервис (`system`)
*Доступен во всех типах хостов.*

Этот сервис предоставляет базовые возможности взаимодействия с ОС:
- **`log`**: Запись в системный лог. (Вход: UTF-8 строка).
- **`fs_read`**: Чтение файла с диска хоста. (Вход: путь; Выход: байты).

---

## 2. Графический сервис (`app`)
*Доступен ТОЛЬКО в `host-gui`. Все методы этого сервиса имеют смысл только в контексте графического интерфейса.*

### Взаимодействие Плагин -> Хост
Методы, которые плагин вызывает у хоста через `call_service("app", ...)`:
- **`display`**: Обновление изображения в окне. Принимает Protobuf `UIDisplayCommand`. Чаще всего используется для передачи готового кадра (RGBA).

### Взаимодействие Хост -> Плагин
Методы, которые плагин **обязан реализовать**, если он хочет работать как приложение:
- **`handle_ui_event`**: Вызывается хостом при кликах, нажатиях клавиш или изменении размера окна. (Вход: Protobuf `UIEvent`).
- **`render`**: Сигнал синхронизации (Heartbeat). Вызывается хостом каждые 16мс (60 FPS) для анимаций и перерисовки интерфейса.

---

## 3. Библиотеки поддержки (Rust SDK)

Для упрощения разработки рекомендуется использовать готовые абстракции:
- **`veldmap-ui-bridge`**: Упрощает отправку кадров в сервис `app`.
- **`veldmap-iced-wasm-runtime`**: Позволяет писать приложения на **Iced**, берет на себя управление очередью событий, шрифтами и оптимизацию отрисовки (Dirty Tracking).

---

## Сборка и запуск

- **Сборка всего проекта**: `python3 build.py build`
- **Запуск GUI**: `python3 run-native.py`
- **Запуск CLI**: `cargo run -p veldmap-host-cli --release`
