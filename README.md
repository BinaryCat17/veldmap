# VeldMap

Современная децентрализованная P2P платформа для визуализации ландшафта, построенная на архитектуре WASM-плагинов.

## Архитектура "Everything is a Plugin"

VeldMap спроектирован как виртуальная операционная система для картографии. Вся логика, сервисы и даже пользовательские интерфейсы (Apps) являются изолированными WASM-модулями, следующими единому стандарту разработки.

- **`core/native`**: Нативный рантайм на Rust. Управляет жизненным циклом плагинов, инициализирует GPU (wgpu) и предоставляет системные сервисы.
- **`modules/core`**: "Мозг" системы (WASM). Логический роутер, управляющий маршрутизацией запросов между плагинами и P2P сетью.
- **`apps/`**: Пользовательские приложения (WASM). Описывают свой интерфейс и логику, используя UI Bridge для отрисовки.
- **`modules/`**: Микросервисы (WASM). Обработка данных, рендеринг, хранилище.
- **`lib/rust/`**: Общие библиотеки (RPC, Математика, Логирование), используемые модулями.
- **`proto/`**: Единый источник истины. Определяет интерфейсы через Protocol Buffers.

## Стандарт Модуля

Каждый WASM-модуль (App или Service) следует строгому шаблону в `src/lib.rs`:
1.  **Конфигурация**: Обязательный файл `config/<имя_модуля>.json`.
2.  **Инициализация**: Автоматический вызов `init` макросом `define_module!`.
3.  **Состояние**: Типизированное состояние `LocalState`, доступное обработчикам.
4.  **Логирование**: Использование стандартных макросов `info!`, `warn!`, `error!`.

```rust
define_module! {
    config: LocalConfig,
    state: LocalState,
    init: handlers::module_init,
    handlers: {
        "method_name" => handlers::handle_request : RequestType => ResponseType,
    }
}
```

## Системные сервисы

Плагины общаются с внешним миром через нативные сервисы Хоста:
- **`system`**: Файловая система, логирование, сеть.
- **`app`**: Управление окном, ввод пользователя и вывод графики (UI Bridge).

## Коммуникация

Все взаимодействия происходят через **Protobuf RPC**:
1. **Local**: Host-to-WASM и WASM-to-WASM (через мост хоста).
2. **Remote**: Между узлами через P2P протокол **Iroh**.

## Разработка

### Сборка всего стека
Сборка RPC-слоя, общих библиотек, всех плагинов и нативного хоста:
```bash
python3 build.py build
```

### Запуск
Запуск нативного рантайма с автоматической загрузкой плагинов:
```bash
python3 run-native.py
```

## Структура проекта
- `/apps` — WASM приложения (GUI).
- `/modules` — WASM микросервисы (Logic).
- `/core/native` — Нативный хост (Runtime).
- `/lib/rust` — Общие библиотеки (RPC Layer, Logger, GeoMath).
- `/proto` — Описания интерфейсов (Protobuf).
- `/config` — Обязательные конфигурации модулей (.json).
- `/plugins` — Скомпилированные .wasm файлы.
