# VeldMap: Децентрализованная P2P ГИС-платформа

Современная модульная платформа для визуализации ландшафта и работы с геопространственными данными. Архитектура построена на изоляции бизнес-логики в WASM-плагинах и использовании P2P-сети Iroh для синхронизации.

## Структура проекта

Проект разделен на три независимых домена:

### 1. [VeldCore](./veldcore) (Ядро платформы)
Содержит реализации хостов и системные протоколы.
- **`veldcore/proto`**: Системные интерфейсы (`services.proto`, `ui.proto`).
- **`veldcore/host/gui`**: Графический клиент (WGPU). Полноценная среда для интерактивных приложений.
- **`veldcore/host/cli`**: Консольный клиент для headless-узлов.

### 2. [VeldSDK](./veldsdk) (Инструментарий разработки)
Единый SDK для создания плагинов. Находится в `veldsdk/rust`.
- **`rpc`**: Генерация системного моста из протоколов ядра.
- **`core`**: Базовые системные функции (логирование, вызовы хоста).
- **`graphics`**: Опциональный мост для отрисовки кадров (`UiBridge`).
- **`iced`**: Опциональный рантайм для создания интерфейсов на [Iced](https://iced.rs/).

### 3. [VeldGIS](./veldgis) (Прикладное приложение)
Пользовательское пространство, превращающее платформу в ГИС.
- **`veldgis/apps`**: Конечные приложения (Data Browser, Desktop Client).
- **`veldgis/modules`**: Функциональные блоки (Render, Tile Server, Data Provider).
- **`veldgis/proto`**: Прикладные ГИС-протоколы.
- **`veldgis/data`**, **`config`**, **`assets`**: Контент и настройки приложения.

## Системные сервисы (API)

### 1. Сервис `system`
*Доступен во всех типах хостов.*
Предоставляет базовые возможности взаимодействия с ОС:
- **`log`**: Запись в системный лог. (Вход: UTF-8 строка).
- **`fs_read`**: Чтение файла с диска хоста. (Вход: путь; Выход: байты).

### 2. Сервис `app`
*Доступен ТОЛЬКО в `host-gui`.*

**Плагин -> Хост** (через `call_service("app", ...)`):
- **`display`**: Обновление изображения. Принимает Protobuf `UIDisplayCommand` (обычно RGBA кадр).

**Хост -> Плагин** (плагин обязан реализовать):
- **`handle_ui_event`**: Вызывается при событиях ввода (Вход: Protobuf `UIEvent`).
- **`render`**: Сигнал синхронизации (Heartbeat). Вызывается каждые 16мс для перерисовки.

## Разработка плагинов

Для создания плагина достаточно подключить `veldsdk`. SDK максимально легкий и позволяет подключать графические возможности через фичи в `Cargo.toml`:

```toml
[dependencies]
# Базовый набор (RPC + Core)
veldsdk = { path = "../../veldsdk/rust" }

# С поддержкой графики и Iced
# veldsdk = { path = "../../veldsdk/rust", features = ["iced"] }
```

Инициализация модуля через макрос:
```rust
use veldsdk::define_module;

define_module! {
    config: MyConfig,
    state: MyState,
    init: my_init_func,
    handlers: {
        "my_method" => my_handler : MyRequest => MyResponse,
    }
}
```

## Сборка и запуск

Для удобства оркестрации в корне проекта находятся Python-скрипты:

- **Сборка всего проекта**: `python3 build.py build`
- **Запуск GUI-версии**: `python3 run-native.py`
- **Очистка артефактов**: `python3 build.py clean`

Каждый домен (`veldcore` и `veldgis`) является независимым Rust-воркспейсом и может собираться отдельно через `cargo build --manifest-path ...`.
